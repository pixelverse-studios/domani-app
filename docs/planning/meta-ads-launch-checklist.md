**Rule:** The campaign does not launch with an incomplete launch blocker.

## Status Key

- `Decided` — the decision is recorded in the campaign plan
- `Ready to verify` — the expected setup is known but must be checked in the live system
- `In progress` — work has started but is not complete
- `Not started` — action is still required
- `Open decision` — Phil and Sami must choose an answer
